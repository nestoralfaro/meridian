# Security Policy

Meridian is a demo application that uses synthetic data only. Security is still treated as a first-class requirement.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private vulnerability reporting instead:
**Security → Report a vulnerability** on this repository.

You can expect an acknowledgement within 3 business days and a status update within 7.

## Supported versions

Only the latest release on `main` is supported.
