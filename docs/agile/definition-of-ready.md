# Definition of Ready

A backlog item moves to **Ready** on the [board](https://github.com/users/nestoralfaro/projects/3) only when:

- [ ] **Value is clear**: a user story ("As a … I want … so that …") or, for chores, the engineering outcome and why it matters now.
- [ ] **Acceptance criteria are testable**: Gherkin scenarios for stories (they become Reqnroll/Playwright specs verbatim), a checklist for chores.
- [ ] **Sized**: story points agreed (Fibonacci); anything above 8 is split.
- [ ] **Dependencies known**: blocking issues linked; required secrets, infrastructure or decisions identified.
- [ ] **Non-functional needs noted**: accessibility, security/privacy, performance, observability, and cost where relevant.
- [ ] **Labeled**: type, area and priority; milestone and sprint set.
